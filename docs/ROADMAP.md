# 逐步工具化路线图

这里列的是计划，不是已实现功能。当前可用能力以 README 和实际脚本为准。

| 优先级 | 工作 | 完成标准 |
| --- | --- | --- |
| P0 | Chromium / Electron 进程沙箱 | 在不增加容器权限的前提下验证可用方案；否则记录外层隔离边界与替代路径 |
| P0 | 第二台空白机器完整复刻 | 从干净克隆到应用、输入、显示、两条访问路径均验收，保留脱敏证据 |
| P0 | 冷启动与故障验收 | 重启全过程、代理中断、DNS 失败均无意外直连；验证共享 namespace 重建行为 |
| P1 | 统一 doctor | 汇总参数、容器、服务、隧道与出网状态；给出可操作诊断，不自动重启生产服务 |
| P1 | 部署配置与代理后端 | 先稳定当前 SS2022 参数；再定义其他代理后端接口，每种独立验证路由与 DNS |
| P1 | 备份 / 恢复 | 分开导出可公开模板和私密运行数据；支持校验、UID/GID 恢复及失败恢复步骤 |
| P1 | 上游补丁维护 | 将整文件覆盖逐步转成可追溯的小补丁，检测上游漂移并拒绝盲目套用 |
| P2 | 跨平台快捷键与输入回归 | Mac 中文、Command/Control、不同 DPI 有明确回归清单与兼容范围 |
| P2 | 应用启动与安装目录 | 扫描 .desktop、展示安装完整性，保留应用版本锁与可恢复安装 |
| P2 | VM / 其他桌面后端评估 | 比较真实隔离和维护成本，先做独立原型，再决定是否进入主部署流程 |

出口地域不设为产品级常量。部署预设只组合参数，不应改变“不直连回退”的网络边界。自动 GeoIP、订阅管理、移动端和多账号能力需要独立设计，首版不承诺支持。
